# 雷电 · THUNDERBOLT

经典纵版空战网页游戏，以原生 JavaScript 与 Canvas 实现。原创程序绘制战机和海岛，无依赖、无外部资源、无后端。

## 开始游戏

直接用浏览器打开根目录的 `index.html` 即可游玩，也可将本目录放到任意静态网页服务器。无需安装依赖或构建。手机与桌面浏览器均可使用。

- **方向键 / WASD**：移动；战机自动射击。
- **空格 / 战场下方炸弹按钮**：释放全屏炸弹，清除敌弹并伤害 Boss。
- **P / Esc / 暂停按钮**：暂停或继续。窗口失去焦点时自动暂停。
- **Enter**：开始、继续或重新开始。
- **M / 顶部声音按钮**：开启或关闭合成音效；默认静音。
- **触屏**：在战场按住并拖动，战机会移动至手指上方。

每局三格生命、三枚炸弹。收集 P 升级至三档火力，B 补充炸弹（最多五枚），+ 恢复生命（最多三格）。受伤后短暂无敌并降一级火力。每个战区约 40 秒后出现 Boss，击败后进入难度递增的下一战区并补充一枚炸弹。最高分和声音设置保存于当前浏览器，禁用存储时仍可玩。

## 验证

使用 Node.js 18 或更新版本，无需 `npm install`：

```sh
npm run check
npm test
```

测试以 DOM / Canvas 适配器运行真实游戏逻辑，覆盖移动边界、自动射击、暂停、受伤无敌、死亡重开、补给上限、炸弹、Boss 和关卡衔接、长时间运行、触控映射及不可用的浏览器存储。该测试不替代真实浏览器中的视觉和音频检查。

## 文件

- `index.html`：中文街机界面与操作说明。
- `style.css`：响应式布局与复古仪表盘。
- `game.js`：固定时间步游戏逻辑、原创 Canvas 图形、Web Audio 音效。
- `tests/game.test.cjs`：零依赖逻辑回归测试。

本项目为致敬纵版街机空战的原创实现，不含原版《雷电》的美术、音频或代码。
